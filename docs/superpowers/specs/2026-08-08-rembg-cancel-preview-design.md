# rembg 取消抠图与大图预览设计

## 目标

为现有同源 Web UI 增加两个能力：

1. 用户可以取消当前抠图请求。
2. 用户可以点击原图或抠图结果查看大图。

保持现有 API 路径、鉴权方式、请求格式和下载行为不变。

## 范围与取消语义

本次取消定义为“取消客户端等待”：

- 尚在推理队列中的请求被取消后，从等待队列移除，不再消耗后续推理槽位。
- 已经开始 GPU 推理的请求不执行不安全的硬中断；推理 worker 安全完成后丢弃结果。
- 浏览器立即结束等待并恢复表单，使用户可以重新选择图片或发起请求。
- 不新增任务 ID、后台任务数据库、状态轮询接口或分布式取消协议。

## 方案

### 前端请求控制

`app/static/app.js` 在每次抠图请求开始时创建 `AbortController`，并将其 `signal` 传给现有 `fetch` 请求。处理中将开始按钮切换为取消按钮；点击取消调用 `abort()`，清理当前请求引用，并恢复输入控件和按钮文案。

`AbortError` 被视为用户主动取消，不显示错误提示；其它网络或服务端错误继续沿用现有错误提示。成功结果创建的 object URL 在替换或重置时释放，避免重复预览造成浏览器内存泄漏。

### 后端取消传播

沿用 `app/remover.py` 当前的取消边界：

- `_acquire_inference_slot()` 等待期间收到取消时，减少等待计数并唤醒其它等待者。
- 推理已经开始后，后台 worker 继续执行；请求协程收到取消后等待 worker 收尾，再释放推理槽。

本次只补齐和验证请求取消场景，不改变同步接口的 PNG 响应格式，也不强制终止 ONNX Runtime/GPU 调用。

### 大图预览

在 `app/static/index.html` 增加可访问的预览弹层，包含关闭按钮和图片容器。原图预览使用现有的本地 object URL；结果预览使用现有的结果 object URL。两张图片都支持点击打开大图，弹层支持：

- 点击遮罩关闭；
- 点击关闭按钮关闭；
- 按 `Esc` 关闭；
- 使用 `role="dialog"`、`aria-modal="true"` 和可读的关闭标签。

预览功能只改变展示层，不改变下载链接；图片加载失败时显示可读的失败状态并允许关闭弹层。

## 测试策略

- `tests/test_remover.py`：验证等待队列中的请求取消后容量和等待计数恢复；验证活动推理取消后 worker 收尾前不释放推理槽。
- `tests/test_ui.py`：验证页面包含取消控件、预览弹层和必要的可访问属性；验证脚本使用 `AbortController`、监听 `AbortError`，并绑定原图和结果预览。
- 运行完整测试套件，确保现有上传、URL、模型切换、下载和安全限制行为不变。
- 本地浏览器验证：发起抠图后点击取消；分别点击原图和结果图打开预览；使用遮罩、关闭按钮和 `Esc` 关闭；确认结果仍可下载。

## 非目标

- 不实现服务端后台任务系统或跨进程取消。
- 不硬中断正在运行的 GPU 推理。
- 不引入 React、Vite 或新的前端依赖。
- 不改变已有 API 合约。
